# vSAN Observability

Metrics and properties of vSAN in VMware Cloud Foundation 9.1, in two sets: what the **vSAN API** returns and what **Broadcom documents** (manuals, KB articles, blogs, VCF Operations reference), plus a comparison of the two.

Start with **[comparison.md](comparison.md)**: summary, findings and the detailed differences.

## Object model

| # | Object type | Notes |
|---|---|---|
| 1 | vSAN Cluster | Includes capacity, health, resync, ESA global deduplication, remote (HCI mesh) client views |
| 2 | vSAN Datastore | vSAN, vSAN Direct and PMem datastores |
| 3 | vSAN Host | ESX host in a vSAN cluster, including witness hosts |
| 4 | Disk Group | vSAN OSA disk group; VCF Operations also calls the ESA equivalent a Storage Pool |
| 5 | vSAN Disk | OSA cache and capacity disks, ESA disks |
| 6 | vSAN Network Adapter | VMkernel adapter and physical NIC used by vSAN |
| 7 | vSAN Object | DOM object (VM home, VMDK, swap, snapshot …) |
| 8 | Virtual Machine | Including VMs on a remote vSAN datastore |
| 9 | Virtual Disk | Including virtual SCSI statistics |
| 10 | File Share | vSAN File Service share (and file server) |
| 11 | iSCSI Target | |
| 12 | iSCSI LUN | |

## Where the data comes from

- **Live:** the vSAN performance service catalog (`VsanPerfGetSupportedEntityTypes`) and the health check catalog (`VsanQueryAllSupportedHealthChecks`) of a VCF 9.1 vCenter, plus vCenter performance counters in vSAN groups.
- **Schema:** all other API fields come from the pyVmomi 9.1 type definitions. The lab has no vSAN cluster yet, so these were not seen with values; they are marked *(schema)*.
- **Documentation:** the sources are listed at the end of each docs file. Only names and identifiers are extracted, not descriptions.

## Rebuild

From the repo root in PowerShell:

```powershell
. tools/env.ps1                      # loads lab values from the git-ignored .secrets/lab.env
.venv/Scripts/python tools/catalog.py    # live catalogs -> raw/catalog.json (needs the lab)
.venv/Scripts/python tools/schema.py     # type definitions -> raw/schema.json
.venv/Scripts/python tools/docs.py       # documentation -> raw/docs.json (needs internet)
.venv/Scripts/python tools/build.py      # -> metrics-api.md, properties-api.md
.venv/Scripts/python tools/compare.py    # -> metrics-docs.md, properties-docs.md, comparison.md
```

Requires Python 3.10+ and pyVmomi 8.0 or later, which includes the vSAN Management API bindings (`vsanapiutils`).
